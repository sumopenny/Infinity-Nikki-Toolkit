# 桌面主页：极简索引

## 已确认的范围

暖立方是无限暖暖的浏览器工具集。主页面向桌面端玩家，提供相册、搭配、家园、相机参数、暖暖档案及现有辅助工具入口。用户选定「极简索引」，要求沿用网站风格，入口文字前保留图标；不增加精选、教程或文章系统。

## 布局与外观

- 左侧为两行标题、打开相册按钮及四项收藏索引；右侧仅保留 16:10 的照片占位，不加载示例图片。
- 底部以小图标和文字呈现头像模拟器、抽卡时间、满进动画、照片解析、电脑清理、备份迁移。
- 复用 `tokens.css` 的浅色／深色主题、暖白表面、柔粉强调、中文无衬线字体和圆角。没有新增外部字体、图片或广告脚本。
- 备份迁移展开导入／导出操作；没有数据时禁用导出。文件操作忙碌时禁用主页入口。

## 行为与实现

- `DesktopHome.vue` 只负责展示并发出导航／工具事件；`App.vue` 调用已有工作区与对话框。
- 桌面没有有效历史模块时默认进入 `landing` 主页；已有模块记忆继续保留。左侧导航可随时返回主页。
- 手机不新增主页底部导航；`landing` 在窄屏归一化为搭配码，与现有相册窄屏规则一致。
- 主页不显示相册搜索、日期筛选或未授权相册提示，不要求目录授权即可显示。

## 验证

本地检查覆盖首页与相册切换、解析入口、备份展开、16:10 比例、1440/1000 宽桌面及 390 宽手机布局、浅色与深色。集成测试使用本地模拟存储，不访问生产 D1。
