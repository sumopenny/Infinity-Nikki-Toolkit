# v3.0 之前的更新记录 / Release history before v3.0

本文件归档 v3.0 之前的中英文更新记录，保留原有文字和顺序。网站更新记录从 v3.0 开始展示。

## 中文

### v2.9 · 2026.11.20

「搭配总结」新增可视化概览。

可查看每月收藏趋势、标签分布和搭配码解析进度。点击标签可查看对应搭配，服装和妆容排行新增单品的出现数占比。

调整更多菜单样式。

手机端「更多」改为侧边栏展开，菜单内容结构优化，按数据备份、应用维护和关于暖立方分组，使用帮助和更新记录置于底部。

新增「返回顶部」按钮。

页面向下滚动后，点击右下角箭头即可回到顶部。

重新整理「使用帮助」。

新版使用帮助按任务提供指引，方便直观查看手势、快捷键和安装方法。

更新提示可以永久关闭。

可选择仅关闭当前版本的提示，或关闭后续所有版本的自动弹窗。仍可从「更多」手动打开更新记录。

优化使用体验。

优化「最近删除」的缩略图加载、拍照动作解析、数据导入和备份恢复。相机参数分包导出中途失败时，已生成的文件仍可从通知下载。

### v2.8 · 2026.11.18

暖暖档案新增「满进动画」。

收录 43 套套装的满进动画，点选套装即可在站内观看，也可跳转到 B 站对应分 P。已收录的套装可从详情页点击「观看满进动画」直达对应视频。

头像模拟器支持动态头像框。

在「工具 → 头像模拟器」中选择支持动画的头像框，即可预览效果，随时暂停或继续播放。同步优化照片裁剪和头像框显示，给边缘特效留出更多空间。

优化手机端暖暖档案布局。

调整档案页签和分类按钮的布局。个人衣橱的收集数量移到「进化形态」开关旁，妆容图鉴的全妆或部件总数移到筛选栏。

### v2.7.2 · 2026.11.16

新增图片旋转功能。

大图预览支持旋转图片，旋转后会保存到原文件。

主题支持跟随系统。

可选择随系统自动切换浅色、深色主题，也可以继续使用固定主题。

相机参数添加封面更方便。

支持拖入图片或 Ctrl+V 粘贴剪贴板中的图片。

完善相机参数解析。

更新后的新增参数支持展示参数中包含的暖暖动作信息。

优化加载体验与使用稳定性。

优化美鸭梨导入速度，完善衣橱、图鉴及数据导入的失败提示。同时优化备份、目录权限和照片导出后的移动处理，并调整部分手机端布局。

### v2.7.1 · 2026.11.13

新增头像模拟器。

在“工具 → 头像模拟器”中选择喜欢的头像框，上传照片后即可拖动调整位置、缩放并保存为 PNG 图片。电脑端还支持从已打开的相册选图，预览区支持滚轮缩放。

手机顶栏新增“工具”菜单。

参数/搭配码解析、头像模拟器、抽卡吉时统一收纳到“工具”中，查找更方便。

优化相册浏览性能。

调整缩略图生成、加载和缓存方式，减少浏览大量照片时的内存占用，改善滚动体验。

自动记住上次浏览的模块。

刷新或重新打开网站时，可恢复到上次使用的页面。

完善备份导入与数据提示。

导入时增加备份类型检查，选错文件时提供更明确的提示。

### v2.7 · 2026.11.11

图片浏览与多选操作调整。

相册、搭配码、家园方案、相机参数及最近删除中的图片，改为单击查看大图。点击图片右下角圆圈可多选，手机端也可长按图片选择。

搭配码新增来源链接，随时回看原帖。

新建或编辑搭配时，可粘贴原帖分享链接，自动提取网址。保存后，点击卡片上的链接按钮即可打开原帖。

美鸭梨数据导入新增用户脚本方式。

在「导入数据 → 从美鸭梨导入 → 脚本法」中按指引安装，即可在美鸭梨页面右下角获取 Cookie，复制后返回工具粘贴。支持有脚本功能的手机浏览器（推荐 Via、X 浏览器）及已安装油猴等类似扩展的电脑浏览器。

新增三种材质风格，更多控件统一显示。

在「视图 → 风格」中选择「实色」「磨砂」「液态玻璃」，应用于顶栏、手机底部导航、大图预览控件及批量操作栏。

手机底部导航新增悬浮胶囊布局。

在「视图 → 导航栏样式」中切换「贴底」或「悬浮胶囊」，可自由搭配材质风格。

优化导航交互与界面展示。

多处分类栏新增滑动选中效果，手机导航增加按压反馈。统一卡片悬浮按钮样式，优化搭配总结布局、手机底部操作栏及安装窗口动画。

优化衣橱浏览。

衣橱套装默认显示全部拥有状态，方便查看已收集和未收集的套装。

### v2.6 · 2026.11.07

全新「妆容图鉴」模块上线！

「暖暖档案」新增「妆容图鉴」，支持查看游戏中的完整妆容及各类妆容部件。可按全妆、底妆、眉妆、睫毛、美瞳、唇妆分类浏览，并根据游戏版本、获取来源、星级等条件筛选，也支持通过名称或 ID 搜索，查找喜欢的妆容更加方便。

妆容详情全面开放，支持关联跳转。

点击妆容卡片即可查看大图、名称、星级、所属版本、获取来源及组成部件。支持切换不同进化形态，查看相关全妆和套装，并可点击对应部件或套装进一步查看详情，让妆容之间的关系更加清晰。

共鸣记录、个人衣橱及搭配解析新增妆容入口。

共鸣记录中，有对应妆容的套装新增「查看妆容」入口；个人衣橱的套装详情也可直接查看关联妆容。搭配码解析时，点击妆容部件查看详情，还能看到对应的全妆名称并跳转查看。多个模块之间可以直接切换，查找妆容、套装与部件更加便捷。

新增背景图自由切换功能。

「暖暖档案」新增背景图切换功能，提供云绸、纱衣、闪烁、幻彩等 9 款不同风格的背景图。可在「视图」菜单中自由选择喜欢的背景，切换后立即生效，并自动记住你的选择，让共鸣记录和个人衣橱的展示更加个性化。

优化图片资源与图鉴数据。

重新整理服装、套装、妆容及拍照相关素材，优化图片加载与展示。补充妆容名称、套装介绍及部分拍照资源，完善中英文资料，并改善部分图片缺失、资源加载失败及图鉴信息显示异常的情况。

全新骨架加载与扫光动画。

相册、搭配码、家园方案、相机参数、共鸣记录、个人衣橱及妆容图鉴等页面的图片加载体验全面优化。新增与内容布局相匹配的骨架占位、柔和扫光效果和加载完成后的渐入动画，减少加载时的空白与突兀感，让浏览过程更加自然。

优化页面切换与卡片动画。

进一步调整卡片出现、加载完成及模块切换时的过渡效果。优化手机端「共鸣记录」「个人衣橱」「妆容图鉴」之间的切换动画和顶部分类栏显示，让页面衔接更加流畅、操作反馈更加自然。

优化界面布局与视觉细节。

调整妆容图鉴、套装详情、筛选菜单和部件详情窗口的排版，优化图片比例、圆角、背景、按钮及悬停效果。同步改善电脑端与手机端布局，让不同页面的视觉风格更加统一。

多项功能修复与稳定性优化。

### v2.5.1 · 2026.11.04

优化界面动画与显示效果。

优化页面卡片、弹窗及部分交互动画，让界面切换更加自然流畅，操作反馈更加细腻，整体视觉体验更加舒适。

### v2.5 · 2026.11.03

从桌面打开暖立方轻量应用。

打开「更多 → 安装应用」，按提示将暖立方添加到手机主屏幕或电脑桌面。安装后，点击图标即可打开；支持的浏览器还可在独立窗口中运行。

新增「搭配总结」。

查看常用标签、常穿部件和常用妆容排行。可按部位筛选，点击标签即可查看对应搭配。优先读取本机已有的解析记录，剩余搭配码可一键批量解析。

优化分享图预览界面。

分享图预览采用与大图预览一致的样式，图片展示更清晰。

只填搭配码也能保存。

新建搭配时，填写搭配码或添加图片，任选其一即可保存。只有图片的搭配会归入「待填写」，方便之后补上搭配码。

### v2.4 · 2026.11.01

新增照片与搭配码分享图功能。

照片支持从卡片或参数窗口进入分享，自由选择附带“图片参数”“穿搭部件”和“相机参数码”；搭配码支持从卡片或解析窗口生成包含搭配图片与搭配码的 9:16 竖版分享卡。

参数解析信息补充。

新增独立的“缩放”倍数，支持显示动态动作的播放进度（仅 2.11 版本之后的照片）。天气信息补充风力和风向，例如“晴天 小风 南风”。

大图预览布局与交互优化。

图片充分利用屏幕空间，风格样式全面优化。

相机参数接入大图预览。

双击有封面的卡片即可查看大图。支持缩放、拖动及前后切换，也可直接复制参数、编辑参数和查看详情。

批量操作工具栏样式优化。

调整为紧凑分组样式，通过文字颜色区分不同操作。

作者主页入口补充。

“更多”菜单新增 B 站主页入口，并更新抖音主页链接。

### v2.3 · 2026.10.30

照片里的穿搭，现在也能解析了！

解析游戏原图，可同时查看拍摄参数和穿搭部件。点击部件还能查看所属套装、进化形态、染色条件，以及染色情况，方便还原喜欢的搭配。

照片解析窗口支持两种布局。

电脑端可自由切换上下排列或左右分栏，并记住你的选择；手机端自动上下排列。同步优化窗口比例、背景和滚动体验，让参数与穿搭更方便对照查看。

衣橱支持合并展示进化形态。

新增“显示进化形态”开关：开启时展示全部形态，关闭时将同系列合并为一张卡片，让衣橱更清爽。显示偏好会自动保存，合并后仍可展开查看其他形态。

套装与部件详情支持快速切换形态。

在衣橱和搭配解析详情中，可直接浏览同系列的不同形态及拥有状态，无需退出后重新查找。

共鸣与衣橱云同步合二为一。

在同一个窗口中管理共鸣记录和个人衣橱，可单独同步，也可一起上传、下载或删除云端存档。操作前可对照本机与云端记录，查看更新时间、覆盖范围和区服变化。

云同步提示更清楚，存档保护更完善。

本机或云端记录发生变化时，会提醒重新确认，避免覆盖刚更新的数据。完善同步失败时的原记录保护；某个模块异常时，也有更明确的提示。

新增“兼容打开（只读）”相册模式。

普通授权无法打开相册文件夹时，可尝试此模式，继续浏览、解析、收藏和导出照片，支持分包 ZIP 下载。照片仅在本地读取，不修改原文件；刷新网页或查看新照片时需重新选择文件夹。只读模式不支持修改备注、删除、恢复和专项清理，收藏与普通模式分别保存。

网站打开更轻快。

衣橱、共鸣、相机参数、解析工具及图鉴内容会在需要时加载，减少首次打开的等待。优化大量参数封面的加载与滚动表现，减少后台资源占用。

加载与重试更顺畅。

页面或窗口加载失败时可重新尝试，导入过程中也能更顺畅地取消退出。修复部分窗口首次打开、关闭后重新打开，以及取消操作后内容再次弹出的问题。

照片解析失败后，重试更方便。

手动输入 UID 后可看到解析进度，失败时会显示更清楚的原因，并方便继续修改重试。补充游戏原图位置提示，帮助确认照片来源。

备份导入提示更易懂。

选错备份类型、文件过大、图片缺失或备份损坏时，会给出对应提示。误将总备份导入相机参数时，会指引前往正确入口；同步优化恢复后的提示和下载保存按钮。

清除数据前，先看清楚、再做决定。

重新优化清除确认窗口，清楚列出会删除和会保留的内容，并新增“先导出备份”快捷入口。

抽卡吉时更新至游戏 2.11 版本。

更新推荐日期、时段、方位与主推排序，新增“需避开生肖”提示，供娱乐参考。

衣橱详情更清晰。

优化套装总览、收集进度、属性、版本、描述和部件列表的排版；电脑端新增来源标签，不同信息使用更容易区分的配色。

手机端浏览更舒适。

优化衣橱形态切换、详情窗口和操作区布局，共鸣页套装快速导航改为双列。

菜单与设置操作更快捷。

电脑端顶部菜单支持鼠标悬停展开。主题与语言切换即时生效，并优化切换动画和选中提示。

统一打磨浅色、深色主题与界面细节。

优化按钮、菜单、标签、输入框、卡片和弹窗的配色、圆角、阴影及操作反馈。同步调整相机参数标签、家园信息区、衣橱提示、共鸣卡片和导入文本框，让各页面的观感更协调，并改善部分旧版浏览器的显示。

其他修复与优化。

修复部分资源数据解析异常，优化缓存清理和导入取消操作。

### v2.1

个人衣橱模块上线：

支持按状态、星级、进化阶段、游戏版本、风格、获取来源、标签及部位筛选。

个人衣橱新增详情查看：

点击套装卡片打开套装详情，查看收集进度、星级、风格、来源版本、介绍及部件列表；点击部件卡片打开部件详情。

共鸣记录支持查看详情：

点击套装图片打开套装详情，点击记录中的部件图片打开部件详情。

搭配码解析新增套装详情入口：

在解析结果中点击部件图片打开部件详情，再点击“所属套装”名称旁的跳转图标，即可查看对应套装详情。

完善衣橱拥有状态识别：
